# CONTROL ESCOLAR
 
Aplicación web para el control escolar de una institución educativa, desarrollada como práctica de la materia Administración de Proyectos.
 
## Módulos

- **Alumnos:** inscripciones, reinscripciones, bajas, cambios de carrera, pagos y evaluación de profesores.

- **Profesores:** CRUD de calificaciones (parciales, finales y extraordinarios), reporte de calificaciones y asistencias.

- **Administrativos Nivel A:** CRUD de materias y horarios de profesores y alumnos.

- **Administrativos Nivel B:** CRUD de pagos, becas y titulación.

- **Director de carrera:** CRUD y evaluación de profesores, carreras, planes de estudio y postgrados.

- **Secretario Académico:** reportes de matrícula, bajas y deserciones, becas y aprovechamiento por grupo, carrera y nivel académico.
 
## Tecnologías

Laravel, JavaScript, HTML/CSS, Git y GitHub.
